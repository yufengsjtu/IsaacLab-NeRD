# Unitree G1 NeRD Train / Eval

本页给出 G1 biped 的 NeRD 数据生成、训练与评估命令，对应上游
`Isaac-Velocity-Flat-G1` / `Isaac-Velocity-Rough-G1`。

以下命令均从 Isaac Lab 仓库根目录运行。

## Train the stock G1 teacher policy

`Isaac-Velocity-Flat-G1` is the upstream G1 flat locomotion task: stock
`g1_minimal` USD, analytical Newton physics, heading-tracking velocity
commands (`vx in (0, 1) m/s`), and the stock RSL-RL agent
(`max_iterations=1500`, `save_interval=50`, `experiment_name=g1_flat`).
Train this policy on the current Isaac Lab stack before running the formal
NeRD mix:

```bash
./isaaclab.sh train \
  --rl_library rsl_rl \
  --task Isaac-Velocity-Flat-G1 \
  --num_envs 4096 \
  --max_iterations 1500 \
  presets=newton_mjwarp
```

The run is written under `logs/rsl_rl/g1_flat/<run>/`. Copy the final
checkpoint, mix snapshots, and saved agent config into the paths consumed by
the formal presets (`save_interval=50`, so iterations 500, 1000, and 1499
are on disk):

```bash
mkdir -p pretrained/control_policy/g1_flat_terrain/params \
  pretrained/control_policy/g1_flat_terrain/checkpoint_mix
cp logs/rsl_rl/g1_flat/<run>/model_1499.pt \
  pretrained/control_policy/g1_flat_terrain/model_1499.pt
cp logs/rsl_rl/g1_flat/<run>/params/agent.yaml \
  pretrained/control_policy/g1_flat_terrain/params/agent.yaml
for it in 500 1000 1499; do
  cp logs/rsl_rl/g1_flat/<run>/model_${it}.pt \
    pretrained/control_policy/g1_flat_terrain/checkpoint_mix/model_${it}.pt
done
```

## Replay collected trajectories

Kinematic replay of recorded ``data/states`` (no policy / physics re-sim).
Randomly samples trajectories unless you pass ``--trajectory-index``.

```bash
PYTHONPATH="$(pwd)/source/isaaclab_neural:${PYTHONPATH}" ./isaaclab.sh -p \
  -m isaaclab_neural.eval.replay_g1_dataset \
  --dataset ./data/datasets/G1-Native-ContactTokens/dataset_valid.hdf5 \
  --num-envs 1 --loop --playback-hz 50 --viz newton
```

Use any mix HDF5 (``dataset_valid``, ``dataset_random_action_valid``,
``dataset_zero_action_valid``, ``dataset_pool_perturbed_random_valid``, …).
``--max-steps 200`` shortens 1000-frame walking clips. Do not pass a NeRD
task; the script launches Dataset-Gen with ``presets=newton_mjwarp``.

## OSMO formal flat training

在 G1 worktree 根目录提交。修复 implicit actuator 的 `joint_f` 输入后，旧的全零力矩数据
不能继续使用：用 `--dataset-cache-mode off` 和新的 `--dataset-subdir` 重新采集，并重新计算
数据统计量、重训 NeRD 模型。原来的 mixed 配比保持不变；teacher policy checkpoint 不需要
因为这次记录修复而重训。

### Shared per-body mix

```bash
./osmo_scripts/start.sh \
  --preset g1_newton_native_shared_per_body \
  --code-dataset IsaacLab-NeRD-Code-G1 \
  --workflow-name g1-shared-mixed-20m \
  --dataset-subdir g1-shared-mixed-20m-jointf-v1 \
  --dataset-cache-mode off \
  --pool <osmo-pool> \
  --priority HIGH \
  --enable-wandb \
  --wandb-exp-name g1-shared-mixed-20m
```

Train cfg：`train/cfg/G1/transformer_native_shared_per_body.yaml`
数据：`G1-Native-ContactTokens/`
优化器与 jiex G1 perturb 对齐：``lr 1e-3 → 1e-4``、head MLP ``[128]``；
八卡、``batch_size: 1024``、``num_iters_per_epoch: 1250`` 仍用 Lab formal。

说明：

- 这条 mix 是默认正式配方。policy-only / random-only / zero-only /
  4:3:3 / checkpoint-only 配方已删除。100% pool-perturb 复现见下一节。
- 六种可配比来源（``dataset_mix.ratios``，顺序固定）：
  policy、random、zero、policy-noise、rl-ckpts、policy-pool-perturbed。
- 默认 ``[2, 0, 0, 2, 2, 4]``，``train_transitions: 20M``，即
  4M clean policy walking、4M policy-noise、4M 3-checkpoint teacher mix、
  8M 从策略状态池出发的随机动作扰动。权重为 0 的来源不会生成
  训练文件，也不会进入 ``train_datasets``。
- 各模式按 Lab-policy 生成器对齐 **wall-clock / 控制步**（本仓库始终按
  physics frame 落盘，``dt=0.005``、``decimation=4``）：
  - clean policy / policy-noise / rl-ckpts /
    policy 与 deployment valid：``trajectory_length: 1000``
    （250 个 control tick）。
  - ``policy_pool_perturbed``：先采与 perturb 训练量相同的
    ``dataset_policy_pool.hdf5``（正式 mix 为 8M，不进训练），再以
    ``initial_states_source=input_states_pool`` 采 **100 个 physics 帧**，
    **每个 physics step 重新均匀抽一条 random action**（对齐 jiex
    ``--perturbed-trajectory-length 100``）。Stock ``G1_MINIMAL`` 的 14 维
    手关节（``*_zero/one/two/three/four/five/six_joint``）不参与 random，
    冻在该条轨迹 reset / pool 姿态；policy / noise / ckpt 仍按 teacher。
    默认 ``perturbed_random_fraction: 1.0``，**不**再采 pool-perturbed zero，
    也 **不** 做 PD 随机。
  - env-reset random / zero（含对应 valid）：``reset_trajectory_length: 500``，
    仍做 ``0.8–1.2`` 相对 PD 缩放。env-reset random 同样冻手；zero 仍是全零 action。
- rl-ckpts 使用
  ``pretrained/control_policy/g1_flat_terrain/checkpoint_mix/``
  中 iteration 500、1000、1499 共 3 个 checkpoint，等分该
  来源的 transition 预算。policy-noise、policy-pool 与 deployment valid 使用
  最终 ``model_1499.pt``。
- policy-noise 为 ``policy_action_noise_std: 0.2``，按 control decimation
  重采样，**不 clip** 到 action bounds（``--no-clip-policy-action-noise``）。
- validation 由 preset 里的 ``dataset_mix.valid`` 声明并生成，和 train
  ``ratios`` 无关。``always: [policy, random, zero, deployment]`` 对应
  ``dataset_valid.hdf5``（10-step eval）、``dataset_random_action_valid.hdf5``、
  ``dataset_zero_action_valid.hdf5``、``dataset_deployment_policy_valid.hdf5``；
  每文件 ``transitions`` 条（正式 250k）。另外再为当前训练 mix 中实际启用
  的来源补 extra valid（默认还有 noisy 与 pool-perturbed random）。
- 命令采样与 Lab-policy 生成器对齐：Dataset-Gen 的 ``vx, vy, yaw`` 独立均匀取
  ``[-1, 1] x [-0.5, 0.5] x [-1, 1]``，``heading_command=False``，每 1 s
  重采一次。policy / deployment / rl-ckpts 走 stock
  ``Isaac-Velocity-Flat-G1``（heading + ``vx in (0, 1)``）。
- 缓存目录：
  ``g1-newton-native-contact-tokens-v3-active-mixed-20m-ckpt3-1499-stock-holdhand``。
  这是相对 23-DoF Hands-Fixed 以及未冻手的 stock 缓存的新路径；不要复用旧目录。

policy 先采 **20M** ``dataset_policy_pool.hdf5``（与 perturb 训练量相同，不进训练），
再从该池抽 perturb。eval 看干净 stock G1 walking（``dataset_valid.hdf5``）。
另外固定采 env-reset random / zero 和 stock G1 deployment valid。
生成长度 / lr / MLP 与 mix 相同；接触仍是 ``contact_tokens`` +
``shared_per_body``。独立缓存，不要复用 mix 或旧的 1M-pool perturb 缓存。

```bash

  --code-dataset IsaacLab-NeRD-Code-G1 \
  --workflow-name g1-shared-perturb-20m \
  --dataset-cache-mode off \
  --pool <osmo-pool> \
  --priority HIGH \
  --enable-wandb \
  --wandb-exp-name g1-shared-perturb-20m
```

Train cfg：`train/cfg/G1/transformer_native_shared_per_body_perturb.yaml`
``num_iters_per_epoch: 2500``（八卡 × ``batch_size: 1024`` ≈ 每 epoch 过完 20M）
缓存：``g1-newton-native-contact-tokens-v3-active-perturb-20m-pool20m-stock-holdhand``

## Notes

- **Robot DoF：** G1 NeRD / Dataset-Gen / teacher 都使用 stock
  `G1_MINIMAL_CFG`（Nucleus `g1_minimal.usd`，含手指驱动关节）。
  Action-mode random / pool-perturb 默认不 random 这 14 维手关节，冻在
  轨迹起点；``--no-hold-g1-hand-actions`` 可关掉。
  `pretrained/control_policy/g1_flat_terrain/` 被 `pretrained/*` 排除，避免把
  大 checkpoint 提交进 git。`osmo_scripts/lib/package_code.py` 会把这些
  gitignored teacher checkpoints 强制打进 OSMO code tarball。
- 正式 preset 要求先在当前 Isaac Lab 版本上训练 stock
  `Isaac-Velocity-Flat-G1`，并把 `model_1499.pt` 与 mix snapshots 放到
  `pretrained/control_policy/g1_flat_terrain/`。policy rollout 同时作为
  validation 数据。
- G1 保留 Implicit PD，不切换到 explicit actuator。采数时，在解析 Newton 步完成后将
  `applied_effort`（shadow PD telemetry，按 backend joint order）写入 `joint_f` 特征；
  NeRD 闭环推理在 actuator telemetry 后、神经求解器前使用同样的特征。浮基的 6 个
  force slots 保持不变。不要在解析 Newton 步之前额外注入这些力矩，否则会重复施加 PD。
  Dataset rollout eval 直接使用 HDF5 的 `joint_f`，不会被当前 actuator telemetry 覆盖。
- NeRD `newton_native` 下关闭 `contact_forces`，`feet_slide` 置空；
  `feet_air_time` / `base_contact` 改用 geometry MDP
  （`.*_ankle_roll_link` / `torso_link`）。
- G1 PD randomization 按 actuator 的 nominal stiffness/damping 做相对缩放；
  OSMO preset 默认范围均为 `0.8–1.2`，每个 env 在一条 trajectory
  开始时采样一次并保持不变。对 G1 **env-reset** 的 zero-action / hold-pose
  数据也会做这组相对缩放（对应参考仓库的 varied-gain passive）。从策略状态池
  出发的 pool-perturb **不**随机 PD。
- G1 Dataset-Gen reset 在默认关节状态上叠加位置 `[-0.2, 0.2]` rad
  和速度 `[-0.1, 0.1]` rad/s 扰动，并在默认 base 高度上叠加
  `[-0.1, 0.1]` m；关节状态会裁剪到 articulation soft limits。
  这些 reset 扰动不作用于 stock teacher 的 policy 数据；policy-pool 扰动从
  策略状态写入仿真，不再走 Dataset-Gen reset。
- Dataset-Gen 的速度命令为独立 ``vx/vy/yaw``，每 1 s 重采；NeRD RL 任务与
  stock teacher 仍使用 G1Flat 命令范围。
